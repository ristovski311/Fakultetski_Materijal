


MEDJUKOD ZA RELACIONE OPERATORE:

1. ==
	Compare_Equal R1, R2

2. <>
	Compare_Equal R1, R2
	Compare_Equal R1, 0
		
3. <
	Compare_Less R1, R2

4. >
	Compare_Greater R1, R2	
	
5. <=
	Compare_Greater R1, R2
	Compare_Equal R1, 0

6. >=
	Compare_Less R1, R2
	Compare_Equal R1, 0
